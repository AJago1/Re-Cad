ALGORITHM FLOW:
1. Random Initial Placement
   - All parts placed randomly in 30x30mm region
   - No overlaps in initial state
   - Random orientations from 24 discrete options

2. Simulated Annealing Loop
   - Select random part each iteration
   - Apply random perturbation (translation OR rotation)
   - Check collision → immediate rejection if collision
   - Calculate energy change
   - Accept/reject based on Metropolis criterion
   - Cool temperature gradually

3. Energy Function (Multi-objective)
   - Primary: Bounding volume (Fogleman's core metric)
   - Height penalty: Quadratic penalty for Z dimension
   - Clustering penalty: CUBIC penalty for part separation
   - XY spread penalty: Force tight XY clustering

================================================================================
ORIENTATION SYSTEM
================================================================================

DISCRETE ROTATION APPROACH:
- 24 total orientations (6 faces × 4 rotations per face)
- Face orientations: ±X up, ±Y up, ±Z up
- Rotations: 0°, 90°, 180°, 270° around up axis
- All rotations in multiples of π/2 radians

ORIENTATION CALCULATION:
```cpp
// Convert orientation ID (0-23) to discrete rotations
int face = new_orientation / 4;        // 0-5 (which face up)
int rotation = new_orientation % 4;    // 0-3 (rotation around face)
float pi_2 = M_PI / 2.0f;

switch (face) {
    case 0: // +Z up (normal)
        roll = 0, pitch = 0, yaw = rotation * pi_2;
    case 1: // -Z up (flipped)
        roll = M_PI, pitch = 0, yaw = rotation * pi_2;
    // ... cases 2-5 for other faces
}
```

BOUNDING BOX TRANSFORMATION:
- Apply Euler rotations to 8 corners of original bbox
- Rotation order: Roll (X) → Pitch (Y) → Yaw (Z)
- Find new axis-aligned bounding box from rotated corners
- Apply translation to final position

================================================================================
COLLISION DETECTION SYSTEM
================================================================================

BVH (BOUNDING VOLUME HIERARCHY) APPROACH:
- 8-leaf BVH per part (triangle-centroid based)
- 1433x speedup over Python implementation
- Gap-free collision detection

COLLISION DETECTION PIPELINE:
1. Generate BVH leaves for each part (8 leaves per part)
2. Apply current transform to get world-space leaves
3. Check all leaf pairs between parts (8×8 = 64 checks)
4. Apply safety margin expansion (2-5mm)
5. Return collision if any expanded leaves intersect

SAFETY MARGIN IMPLEMENTATION:
```cpp
const float SAFETY_MARGIN = 5.0f;  // 5mm for visual separation

// Expand both leaves by safety margin
my_expanded.min -= SAFETY_MARGIN;
my_expanded.max += SAFETY_MARGIN;
other_expanded.min -= SAFETY_MARGIN;
other_expanded.max += SAFETY_MARGIN;

// Check intersection of expanded leaves
return my_expanded.intersects(other_expanded);
```

COLLISION METHODS AVAILABLE:
- BVH_8_LEAF: High-precision 8-leaf BVH (default)
- CONVEX_GJK: Convex hull with GJK algorithm (fallback)

================================================================================
ENERGY FUNCTION DETAILS
================================================================================

MULTI-OBJECTIVE ENERGY FUNCTION:
Designed for aggressive tight packing with flat orientation preference

ENERGY COMPONENTS:
1. Bounding Volume (Primary - Fogleman's metric)
   - Volume = (max_x - min_x) × (max_y - min_y) × (max_z - min_z)
   - Weight: 1/1000.0 (base metric)

2. Height Penalty (Aggressive)
   - Penalty = height² × 10.0 (quadratic)
   - Weight: 1/100.0
   - Purpose: Force flat packing

3. Clustering Penalty (Very Aggressive)
   - Distance from center of mass for each part
   - Penalty = distance³ (CUBIC penalty)
   - Weight: 1/20.0
   - Purpose: Pull scattered parts together

4. XY Spread Penalty (Aggressive)
   - Penalty = (width × depth) × 5.0
   - Weight: 1/200.0
   - Purpose: Force tight XY clustering

TOTAL ENERGY CALCULATION:
```cpp
float total_energy = (bounding_volume / 1000.0f) +     // Base Fogleman
                    (height_penalty / 100.0f) +        // Heavy height penalty
                    (clustering_penalty / 20.0f) +     // VERY HEAVY clustering
                    (xy_spread_penalty / 200.0f);      // XY spread penalty
```

MESH-TO-ACTOR CONVERSION:
```python
def mesh_to_actor(self, mesh, color=(0.2, 0.6, 0.9), opacity=1.0):
    # Export trimesh to temporary STL
    with tempfile.NamedTemporaryFile(suffix='.stl') as tmp:
        mesh.export(tmp.name)
        
        # Read with VTK
        reader = vtk.vtkSTLReader()
        reader.SetFileName(tmp.name)
        reader.Update()
        
        # Create mapper and actor
        mapper = vtk.vtkPolyDataMapper()
        mapper.SetInputConnection(reader.GetOutputPort())
        
        actor = vtk.vtkActor()
        actor.SetMapper(mapper)
        actor.GetProperty().SetColor(color)
        actor.GetProperty().SetOpacity(opacity)
        
    return actor
```
